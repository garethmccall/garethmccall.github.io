How syncing works without a server

Sync DJ keeps devices in time by agreeing on a shared start time, then having each device independently calculate its own playback position from the current time. There's no live connection between devices during playback — which also means there's nothing for Sync DJ to see, log, or relay.

To correct for differences between device clocks, Sync DJ can optionally query Apple's public NTP server (time.apple.com) to measure the offset between the device clock and network time. This is a single UDP packet containing only timestamp fields — no user data, device identifiers, or app information is included. The feature is on by default and can be toggled off in the Drop Time panel, in which case no network requests are made at all.

What's stored, and where

A handful of settings are saved to your device's local settings storage (iOS UserDefaults) so the app remembers your setup between launches:

  • The scheduled start time you've set
  • The file name of your chosen audio track
  • The NTP clock offset and when it was last measured (so the correction survives an offline relaunch)
  • Whether internet time sync is enabled
  • Your chosen color theme

Sync DJ also keeps a security-scoped bookmark — an iOS mechanism for remembering which file you picked — so it can reopen that file the next time you launch the app, without asking you to re-select it. This bookmark, like everything above, stays in your device's local storage. None of it is sent anywhere.

Sharing a session

When you share a start time — by copying a syncdj:// link or using the iOS share sheet — that link contains only the start time and (optionally) the file name you're using. Sync DJ builds this link entirely on your device and hands it to whatever share method you choose (Messages, AirDrop, email, or otherwise). We never see it, receive it, or store a record of it.

Background audio

Sync DJ uses iOS's background audio capability so playback keeps running when your screen is locked or you switch apps — the same way any music app does. This permission is used solely for continuous playback and involves no data collection.

Children's privacy

Sync DJ is not directed at children and collects no personal information from anyone, regardless of age.

Changes to this policy

If this policy ever changes, the effective date above will be updated. Given that Sync DJ collects nothing today, we don't expect much to change — but if the app's data practices ever do, this page will reflect it before that update ships.
