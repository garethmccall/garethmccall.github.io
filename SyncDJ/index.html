Privacy Policy

How syncing works without a server

Sync DJ keeps devices in time by agreeing on a shared start time, then having each device independently calculate its own playback position from the current time. There's no live connection between devices during playback — which also means there's nothing for Sync DJ to see, log, or relay.

What's stored, and where

Three things are saved to your device's local settings storage so the app remembers your setup between launches:

  • The scheduled start time you've set
  • Your sync offset adjustment (used to correct for speaker distance or device latency)
  • The file name of your chosen audio track

Sync DJ also keeps a security-scoped bookmark — an iOS mechanism for remembering which file you picked — so it can reopen that file the next time you launch the app, without asking you to re-select it. This bookmark, like everything above, stays in your device's local storage. None of it is sent to us, because we don't operate any server to send it to.

Sharing a session

When you share a start time — by copying a link, using the iOS share sheet, or showing a QR code — that link contains only the start time and (optionally) the file name you're using. Sync DJ builds this link entirely on your device and hands it to whatever share method you choose (Messages, AirDrop, email, or otherwise). We never see it, receive it, or store a record of it.

Background audio

Sync DJ uses iOS's background audio capability so playback keeps running when your screen is locked or you switch apps — the same way any music app does. This permission is used solely for continuous playback and involves no data collection.

Children's privacy

Sync DJ is not directed at children and collects no personal information from anyone, regardless of age.

Changes to this policy

If this policy ever changes, the effective date above will be updated. Given that Sync DJ collects nothing today, we don't expect much to change — but if the app's data practices ever do, this page will reflect it before that update ships.
